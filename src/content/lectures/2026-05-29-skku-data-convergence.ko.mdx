- **형식:** 데모 중심 + 선택 핸즈온. 설치는 선택이었고, 설치한 분은 옆에서 같이 따라 했다

## 왜 이 강의였나

교실에서 준비한 7~8월 본 교육의 리허설 자리였다. 청중은 공학·바이오·의공학 배경의 대학원생과 연구원이 중심이라 코딩과 데이터가 낯설지 않았다. 그래서 설치 안내는 짧게 하고, 셋업 구조와 활용 사례에 시간을 썼다.

한 가지를 깊게 하기보다 여러 주제를 짧게 보여주고, 마지막에 본 교육에서 다룰 주제를 함께 고르는 구성으로 짰다.

## 무엇을 다뤘나

앞부분은 내 Claude 셋업 전체 구조였다. 스킬, MCP, 메모리와 하네스, 그리고 Obsidian으로 쌓은 2nd Brain을 화면으로 보여줬다. *프롬프트 → 컨텍스트 → 스킬 → MCP → 하네스*의 5단계 계단을 소개하면서, 한 번에 다 올라갈 필요 없이 한 층씩 쌓으면 된다고 말했다.

메인 데모는 CSV 한 개에서 시작했다.

- `/deidentify`로 식별자를 먼저 지우고
- `/clean-data`로 변수 타입·결측·이상치를 점검하고
- `/analyze-stats`로 Table 1, `/make-figures`로 Figure를 만든 뒤
- 같은 데이터로 HTML 프로토타입 도구까지 이어갔다

공대 청중을 위해 변수 타입 추론이 어디서 틀리는지, 결측·이상치 처리가 도메인 감각과 맞는지처럼 사람이 개입해야 할 지점을 같이 짚었다. 안과 교수님 의뢰로 만든 드림렌즈 피팅 MVP, 컨텍스트 위생과 토큰 사용량 관리도 다뤘다.

## Co-Scientist 사례

MI2RL에서 개발 중인 보안형 multi-agent 연구 자동화 사례를 소개했다. 병원 안의 on-prem LLM이 환자 데이터를 처리하고, Sentinel 역할의 LLM이 외부로 나가는 내용을 검수하며, 일부 역할만 상용 LLM을 쓰는 구조다.

## 앞으로

마지막 장에는 7~8월 본 교육 주제 후보 여섯 가지(연구 자동화, 데이터 분석 워크플로우, 자연어로 도구 만들기, Agentic AI·Co-Scientist, 2nd Brain·MCP·하네스 셋업, 안전·거버넌스)를 올리고 청중에게 고르게 했다. 자리를 만들어 주신 교실 구성원분들께 감사드린다.
